II. WHAT I LEARNED

Better understood how parameters, arguments and return values work together when data is passed between functions.

Better understood how a value from one function can become an argument for another function.

Better understood local variables and variable scope.

Better understood the difference between the overall program state and the user session state.

Practiced using separate state variables such as program_running and session_running.

Better understood how functions can depend on each other and exchange data.

Practiced reading traceback information and following the chain of function calls leading to an error.

Improved my understanding of code organization, naming and readability.

Deeper understanding of program state and control flow between different levels of a program.

Further understanding of dependencies and data flow between functions in larger programs.

Further practice with reading tracebacks and understanding how errors propagate through function calls.
